
# Aether AI

## 1. Présentation

Aether AI est une plateforme d'intelligence documentaire qui permet
d'interroger des documents techniques en langage naturel.

Le projet vise à construire progressivement un système capable de
retrouver des informations pertinentes, de générer des réponses
fondées sur des sources vérifiables et, à terme, d'exécuter des
tâches contrôlées grâce à un agent IA.

## 2. Problème

La recherche manuelle dans de grandes quantités de documentation
est longue et peut rendre difficile l'identification des informations
pertinentes.

Aether AI cherche à rendre cette recherche plus rapide, accessible
et vérifiable.

## 3. Première version (MVP)

- Importer des documents PDF.
- Extraire et indexer leur texte.
- Poser des questions sur leur contenu.
- Générer des réponses à partir des passages pertinents.
- Afficher les sources utilisées.
- Signaler les informations insuffisantes.

## 4. Technologies envisagées

- Python et FastAPI pour le backend.
- React et TypeScript pour le frontend.
- PostgreSQL pour les données applicatives.
- Un modèle d'IA générative pour les réponses.
- AWS pour le stockage, l'exécution et la supervision.

Les technologies définitives seront sélectionnées selon les besoins,
la sécurité, la complexité et le coût.

## 5. Principes de conception

- Réponses vérifiables et sources traçables.
- Protection des données et des secrets.
- Tests automatisés.
- Architecture modulaire.
- Maîtrise des coûts cloud.
- Documentation des décisions techniques.

## 6. Évolutions futures

- Recherche sémantique avancée.
- Évaluation de la qualité des réponses.
- Gestion des utilisateurs et de leurs documents.
- Agent IA utilisant des outils autorisés.
- Déploiement et supervision sur AWS.
